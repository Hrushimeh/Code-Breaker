# 🔐 Code-Breaker

## 👋 Welcome

Hello! Welcome to the Code-Breaker repository. 🎉

## 📝 Description

This program is a version of the popular board game known as **MasterMind**. 🎮 It has both the option for the user to play, or play with their own code and allow the code's algorithm to guess. 🤖

### ✨ Features

- 🎯 **Player Mode**: Test your code-breaking skills against the AI
- 🤖 **AI Mode**: Let the computer guess your secret code
- 🎨 **Six Color Options**: G (Green), P (Purple), Y (Yellow), O (Orange), B (Blue), R (Red)
- 🔢 **Customizable Code Length**: Choose from easy, medium, hard, or custom difficulty
- 💡 **Smart Feedback System**: Black (right letter, right spot), White (right letter, wrong spot), Gray (nothing)
- 🎵 **Audio Effects**: Includes win and loss sound effects

## 🚀 Getting Started

To get started with Code-Breaker:

1. ☕ Ensure you have Java installed on your system
2. 📥 Clone this repository to your local machine
3. 🔨 Compile the Java source files
4. ▶️ Run the CodeBreaker program to start playing

### 📦 Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd Code-Breaker

# Compile the Java source
javac CodeBreaker.java

# Run the game
java CodeBreaker
```

## 🎮 Usage

1. **Choose Your Mode**:
   - 🎯 Select "Guess" to play against the AI
   - 🤖 Select "AI Guess" to let the computer guess your code

2. **Set Difficulty**: Choose from easy, medium, hard, or custom code length

3. **Play the Game**:
   - Enter your guesses using the available color letters (G, P, Y, O, B, R)
   - Review the feedback after each guess
   - Try to crack the code within 10 attempts!
