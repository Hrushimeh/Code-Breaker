# Code-Breaker

## Welcome!

Hello and welcome to the Code-Breaker repository! We're excited to have you here.

## About

This program is a version of the popular board game known as MasterMind. It has both the option for the user to play, or play with their own code and allow the code's algorithm to guess.

## Getting Started

To get started with Code-Breaker, you'll need:
- Java Development Kit (JDK) installed on your system
- A Java IDE or command-line compiler

### Running the Program

1. Clone this repository to your local machine
2. Compile the Java source file: `javac CodeBreaker.java`
3. Run the program: `java CodeBreaker`
4. Follow the on-screen instructions to play the game or let the AI guess your code

Enjoy breaking codes!
